# Simple Media Downloader

Windows 11 x64向けの、日本語で使える動画・音声ダウンローダーです。

このリポジトリは、配布ファイル、リリースノート、利用案内、不具合報告・要望の窓口として使用します。

## 配布状況

初版の公開準備中です。現在、ダウンロードできる正式リリースはありません。
公開準備が完了した配布ファイルは [Releases](https://github.com/legion-edge/simple-media-downloader-releases/releases) に掲載します。

対応予定の初版はWindows 11 x64向けです。初版ではWindowsコード署名を行わない方針のため、導入時に発行元やアプリの信頼性に関する警告が表示される場合があります。

## 不具合報告・要望

[GitHub Issues](https://github.com/legion-edge/simple-media-downloader-releases/issues) を主な窓口として受け付けます。日本語で投稿できます。

不具合の報告には、アプリのバージョン、Windowsのバージョン、再現手順、期待した結果と実際の結果を記載してください。個人情報や認証情報を含むログは掲載しないでください。

Xの補助窓口は、アカウントの準備後に案内します。

## ソースコード・利用条件

アプリの開発リポジトリは非公開です。このリポジトリではアプリ本体のソースコードを公開しません。

アプリ本体の利用条件は初版公開前に案内します。現時点でMITなどのオープンソースライセンスは採用していません。
同梱ソフトウェアについては、それぞれに適用されるライセンス・第三者告知および必要な対応ソースの提供方法を配布時に案内します。
